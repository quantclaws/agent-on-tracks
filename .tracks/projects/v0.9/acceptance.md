# Web 后台持续驱动与最小工作台（v0.9） — 验收标准

> 本文档为 SPEC-009（FR-0288..FR-0315、NFR-0150..NFR-0152）验收标准的唯一登记处；每条 AC 只写可从系统外部观察、可断言的通过条件。story 的发布验收脚本（登记→创建→澄清批准→关浏览器自动推进→注入等待与重启→pause→回拨→发布→hotfix 两旅程）由下述 AC 组合覆盖：纵向闭环主链为 AC-FR0288-01 → AC-FR0289-01 → AC-FR0290-01 → AC-FR0291-01 → AC-FR0293-01 → AC-FR0308-01 → AC-FR0297-01 → AC-FR0298-01/AC-FR0300-01 → AC-FR0310-01 → AC-FR0312-01 → AC-FR0309-01，另以 AC-FR0292-01 验证 post-release/dev 两旅程，以 AC-FR0313-03 验证退出/取消/真实不可恢复错误的明确终态（脚本第 8 步）。

## FR-0288 Web 服务生命周期

### AC-FR0288-01

- 执行一条启动命令后，健康检查端点返回可用状态与已登记项目数；工作台可访问。
- 浏览器全部关闭期间，一个 run 经历至少一次自动阶段转移；重新打开工作台可见该推进轨迹。

### AC-FR0288-02

- 显式停止服务并重启后：已登记项目仍在，进行中/等待中的命令与等待状态（含 retry_at）恢复，工作台状态连续可解释。

### AC-FR0288-03

- 健康检查未通过时（注入不可用依赖），工作台入口不呈现"可用"假象，启动输出给出具体原因。

## FR-0289 项目登记与选择

### AC-FR0289-01

- 在许可范围内登记仓库后，界面显示归属仓库与版本；该归属在所有该项目的 run 操作界面一致呈现。
- 服务重启后登记仍在（不需要重新登记）。

### AC-FR0289-02

- 提交许可范围外的仓库登记被拒绝，并显示具体原因；未登记项目不可创建 run。

## FR-0290 运行环境就绪检查

### AC-FR0290-01

- 运行就绪检查后，逐项显示合同、harness/model、凭据引用、必需工具的就绪状态。

### AC-FR0290-02

- 构造一项未就绪（如缺失工具），检查显示该项与具体原因；此时新建 run 入口给出原因且不创建 run；修复后重查该项转为就绪并可创建 run。

## FR-0291 Feature story 创建

### AC-FR0291-01

- 提交 story 内容与版本后返回持久 command_id 与 run 标识；新 run 出现在总览并处于待澄清/待推进状态。

### AC-FR0291-02

- 提交失败（构造校验失败）时返回明确错误且系统内不产生该 run。
- 同一提交重复发送（模拟刷新/超时重试）返回同一 run，不新建。

## FR-0292 两类 hotfix 入口

### AC-FR0292-01

- 经 Web 入口分别运行 post-release 与 dev 两类 hotfix 至终态；dev 旅程完成后不存在公开 release 产物。

### AC-FR0292-02

- 前置检查不满足（构造）时，提交被拒绝并显示具体原因，系统内不产生该 run。

## FR-0293 需求澄清交互

### AC-FR0293-01

- run 进入澄清等待后，待办中心/run 详情出现提问；用户回复后 run 在同一 run 标识内继续推进（run 标识不变，无新 run 产生）。

### AC-FR0293-02

- 讨论历史（提问、回复、时间、操作者）在该 run 界面完整可回溯。

## FR-0294 需求与设计材料审阅

### AC-FR0294-01

- 审阅界面显示 story/spec/acceptance/design 当前内容与 revision 标识；待批准条目显示对象 revision 且与用户实际审阅的 revision 一致。

### AC-FR0294-02

- 相邻 revision 之间存在可见变更对比；revision 变更后（注入修订）界面显示新 revision。

### AC-FR0294-03

- 经编辑界面修改材料后产生新 revision；待批准条目更新为该 revision；对旧 revision 的批准按 AC-FR0308-02 被拒绝。

## FR-0295 持久命令受理与去重

### AC-FR0295-01

- 任一命令入口提交后先返回持久 command_id；服务重启后该 command_id 及其结果仍可查询。

### AC-FR0295-02

- 以相同幂等键重复发送同一命令（含 HTTP 超时后重试、双击提交）只产生一次业务效果（一个 run/一次批准/一次 pause）。

### AC-FR0295-03

- 同一命令分别经 CLI 与 HTTP 提交，产生的事件类型与业务效果等价。

### AC-FR0295-04

- 查询类请求执行前后事件序列与状态投影不变（只读）。

## FR-0296 单一有效执行者与活动 run 上限

### AC-FR0296-01

- 并发触发同一 run 推进（并发请求 + 并发启动两个服务实例）后，不存在同一阶段的重复派发，外部副作用（发布类）只发生一次。

### AC-FR0296-02

- 构造租约过期场景：新 worker 接管后，旧 worker 迟到结果被隔离并在事件中留有审计记录，run 状态不受其影响。

### AC-FR0296-03

- 第二个已受理 run 在第一个活动 run 期间显示为排队状态，不并发推进。

### AC-FR0296-04

- feature 活动 run 推进中提交 hotfix 紧急 run：经 pause 活动 feature → hotfix 插队推进至发布 → resume feature 全过程；换队各步骤经命令服务受理并在时间线留下审计记录（操作者与命令标识）；换队期间无双重 dispatch；换队完成后 feature run 从原合法位置继续。

## FR-0297 全阶段自动推进

### AC-FR0297-01

- 完成澄清与必要批准后关闭浏览器，run 沿阶段流程自动推进至人工门或终态；全程无需人工执行命令。

### AC-FR0297-02

- 运行至每个原合同要求的人工门时 run 停止推进；不作出决定则不越过。

## FR-0298 外部等待与重试

### AC-FR0298-01

- 注入可恢复外部等待后，界面显示持久等待原因与 retry_at；服务重启后该显示不变；条件满足后 run 自动恢复推进。

### AC-FR0298-02

- 等待期间系统对该外部条件的请求频率不超过 NFR-0152 口径（无热循环）。

## FR-0299 额度等待与续跑

### AC-FR0299-01

- 注入带已知 reset 时间的配额信号后，等待状态显示额度等待与恢复时间且持久保存；到达 reset 时间后无人工干预自动续跑。

### AC-FR0299-02

- 注入未知 reset 时间的配额信号后，显示探测计划而非倒计时；探测间隔符合 NFR-0152 口径；该等待不出现在待办中心。

## FR-0300 崩溃重启恢复

### AC-FR0300-01

- 在 worker 执行中重启 worker：该命令被找回并重新认领，未完成步骤继续，已完成的外部副作用不重复执行（外部结果唯一）。

### AC-FR0300-02

- 在 server 重启场景中：等待状态与 retry_at 保留；重启后恢复推进的全过程无丢单、无重复发布。

## FR-0301 Run 列表与总览

### AC-FR0301-01

- 总览显示当前/历史 run 的版本、状态、待人工处理数量，与各 run 实际状态一致。

### AC-FR0301-02

- 长任务运行期间发起查询，查询即时返回且事件序列不变（只读、不阻塞推进）。

## FR-0302 阶段与任务进度

### AC-FR0302-01

- 详情页显示当前阶段、任务完成情况、质量状态；测试计数与需求子句闭合计数分别呈现。

### AC-FR0302-02

- 展示的进度数值可对应到系统中的真实计数（抽查断言），无编造百分比。

## FR-0303 Agent 执行状态

### AC-FR0303-01

- 详情页显示各角色/任务的执行状态（执行中/等待/失败）并可跳转到对应日志。

### AC-FR0303-02

- 界面与导出中不出现 Agent 会话内容/会话视图。

## FR-0304 AC 及验证证据视图

### AC-FR0304-01

- 每个 AC 可追踪到测试 node、实际结果、候选与证据；链路在界面完整呈现。

### AC-FR0304-02

- 构造缺失/过期/未审阅的证据，对应 AC 明确标注该状态。

## FR-0305 事件与失败诊断

### AC-FR0305-01

- 时间线展示事件、错误、重试次数、阻断原因与下一步；与实际发生一致。

### AC-FR0305-02

- 任一错误可按 run/command/task/AC 维度定位到日志记录。

## FR-0306 实时状态与断线重连

### AC-FR0306-01

- 在线期间状态变化在无人工刷新的情况下更新到界面。

### AC-FR0306-02

- 断线期间产生若干事件后重连，界面补齐全部缺失事件；注入重复/乱序事件后界面不回退。

## FR-0307 人工待办中心

### AC-FR0307-01

- 合法人工决定（批准、发布等）出现于待办中心并附理由、上下文与跳转入口；candidate 进入可发布状态即出现发布待办。

### AC-FR0307-02

- 构造 quota/CI 等待，该等待不出现在待办中心。

## FR-0308 阶段批准与修订决定

### AC-FR0308-01

- 对当前 revision 作出批准：系统记录操作者、审阅 revision 与决定（可查询的审计记录），run 自动推进下一阶段。

### AC-FR0308-02

- 构造 revision 过期后提交批准：批准被拒绝，提示当前 revision，状态不推进。

## FR-0309 发布预览与三择一决定

### AC-FR0309-01

- 全部门通过后发布待办出现；审阅 preview 显示 digest 与过期状态；执行 release 后显示真实远端发布结果并可查 AC 证据链。

### AC-FR0309-02

- 构造 preview 过期后提交 release：被拒绝，run 停留在可发布/等待状态，无发布副作用。

### AC-FR0309-03

- delay 与 return 决定各自产生明确终态并绑定决定时审阅的 digest；决定可审计。

## FR-0310 暂停与继续

### AC-FR0310-01

- 请求 pause 后界面先显示"已接收"再显示"已暂停"；暂停期间注入外部条件满足（retry_at 到期/额度恢复），run 保持暂停。

### AC-FR0310-02

- resume 后 run 从暂停前的合法位置继续，已完成工作与证据保留。

## FR-0311 失败后的受控重试

### AC-FR0311-01

- 构造可恢复失败并修复条件后，经控制区重试：run 从原合法位置继续推进，全程不重复已发生的外部副作用。

### AC-FR0311-02

- 对证据过期的失败发起重试：被拒绝并说明原因（不复活过期证据）；对不可恢复错误不提供重试入口。

## FR-0312 阶段回拨

### AC-FR0312-01

- 发起回拨：仅能选择 Runtime 允许的上游阶段；确认前显示将失效的证据与影响；确认后 run 回到目标阶段重新推进。

### AC-FR0312-02

- 回拨后注入旧 worker/旧 Agent 迟到结果：该结果被隔离，不推进被回拨的流程；下游证据标明失效并在重验后恢复。

### AC-FR0312-03

- 对已推送 tag/release 的 run 发起回拨：远端 tag/release 仍存在，影响清单如实列出已发生副作用。

## FR-0314 人工身份与访问控制

### AC-FR0314-01

- 未认证访问任一工作台页面/API 返回拒绝（登录页/401）；认证后可访问。

### AC-FR0314-02

- 以非人类身份（后台/Agent 凭据）提交批准或发布决定：被拒绝且审计记录包含该尝试；不产生状态推进。

### AC-FR0314-03

- 经 HTTP 提交任意 shell 类命令载荷：被命令防护拒绝，无执行效果。

### AC-FR0314-04

- 请求 Human/指定评审者裁决的讨论线程：由非被请求方执行 resolved 操作无效（状态不变并可审计）；由被请求方经认证入口响应后 resolved 生效。

## FR-0315 凭据与信息暴露边界

### AC-FR0315-01

- 对全部 UI 页面、API 响应与服务日志进行密钥扫描：无明文凭据（凭据仅以受控引用出现）。

### AC-FR0315-02

- 构造授权项目与证据范围外的文件/产物读取请求：被拒绝并记录。

## NFR-0151 可靠性测试覆盖

### AC-NFR0151-01

- 八类场景（服务重启、断网、模型额度、重复/并发请求、并发 worker、UI 断线重连、旧 worker 迟到结果、人工 pause 竞态）各存在至少一条自动化测试并纳入质量门。

### AC-NFR0151-02

- 质量门含 v0.8 继承的覆盖率门槛且在本版通过。

## NFR-0152 等待探测与轮询上限（规格期锁定口径）

### AC-NFR0152-01

- 注入未知 reset 时间的额度等待：观测探测间隔从初始值（默认 60s）按退避增长且不超过上限（默认 15min）；配置项可读出该默认值。

### AC-NFR0152-02

- UI 实时通道断开时回退轮询间隔不超过空闲上限（默认 60s）；服务空闲（无活动 run）时无持续轮询负载（可观测请求频率为零或低于空闲口径）。
