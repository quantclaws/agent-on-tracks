# 真实新用户验收：安装预检

真实 Agent 验收使用 `tests/e2e_live/harness.py::prepare_live_install` 构建 wheel，创建隔离 Python 环境，安装包并从安装路径导入 CLI/Web 和物化 Agent 资源。该阶段不需要模型或 GitHub 凭据，不产生真实 Agent 成功证据。

2026-11-11 在全新目录实跑此入口，原实现首先拒绝了发行包合法携带的 demo_host/reference_host 测试。这些测试是宿主物化能力的产品资源，不是验收驱动或预制 Agent 结果。过滤器现只允许这两个产品资源目录，仍拒绝顶层 tests、e2e_live、scenarios 和其他宿主测试目录的泄漏。

隔离安装此前使用 `--no-deps`，不能保证 CLI/Web 的真实运行依赖存在。现在按正常 pip 安装解析运行依赖，使用 `pip check` 检查一致性，并在隔离进程实际导入 CLI 与 Web 入口。重试安装使用 `--force-reinstall`，避免同版本的旧包被误当作当前候选。

重复准备外部 OpenCode 链接此前可能抛 SameFileError；替换链接时还可能沿旧符号链接覆盖外部可执行文件。现在复用相同链接，变更目标时只替换验收工具自己的链接，并用测试保护旧可执行文件字节不变。

新增 `tests/e2e_live/test_install_preflight.py` 进行真实 wheel/依赖安装，使用一经调用即失败并留痕的外部 CLI 脚本，证明安装预检不会触发模型请求。该预检已通过；资源过滤与链接行为 8 项测试通过；既有不调用模型的配置、派发预算、日志及进程清理回归也通过。模型调用类用例明确未执行，不能计为成功。
